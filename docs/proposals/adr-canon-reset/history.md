## Source limitations

- The two previous ignored October 28 packets referenced by Linear are unavailable on this host. Their review claims are issue-reported, not reproduced here.
- Linear issue snapshots preserve direction and status. Private Claude artifacts linked from them were not read, and not every unmerged branch was enumerated.
- Wayfinder found saved app locks with unknown freshness and absent topo stores. It supplied artifact provenance, not a current-source or runtime conformance certificate.
- Draft implementation evidence does not ratify its prose. Accepted target-state doctrine does not prove implementation. Both distinctions constrain the proposed canon.
- Historical commit titles led discovery; pivotal diffs and current-source checks supported synthesis. A documentation commit alone is not labeled a runtime implementation.
